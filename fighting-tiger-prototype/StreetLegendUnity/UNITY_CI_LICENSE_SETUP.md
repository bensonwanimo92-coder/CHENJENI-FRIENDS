# Street Legend — Unity CI licence setup

The Android build workflow is ready, but GitHub Actions cannot run Unity until a valid Unity licence is supplied. Do not commit a licence file, Unity password, or serial key to the repository.

## For Unity Personal

1. Open Unity Hub on a computer signed in to the Unity account that will own the project.
2. Open **Preferences / Settings → Licenses** and activate the **Personal** licence.
3. Locate the Unity licence file generated by Unity Hub:
   - Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
   - macOS: `/Library/Application Support/Unity/Unity_lic.ulf`
   - Linux: `~/.local/share/unity3d/Unity/Unity_lic.ulf`
4. Open this GitHub repository and go to **Settings → Secrets and variables → Actions**.
5. Create a repository secret named exactly `UNITY_LICENSE`.
6. Paste the complete contents of the `.ulf` file into the secret and save it.

Do not paste the licence contents into a chat, issue, commit, or ordinary repository variable.

## For Unity Pro / Plus

Use the matching GameCI professional-licence setup instead: add `UNITY_EMAIL`, `UNITY_PASSWORD`, and `UNITY_SERIAL` as Actions secrets. Do not use the Personal workflow for a Professional licence.

## Start the build

After the secret is saved, open **Actions → Street Legend Unity Android Build → Run workflow** on the `main` branch. The workflow generates the Main Menu and Hotel Prototype scenes in batch mode, builds an ARM64 Android APK, verifies that the APK exists, and uploads it as the `StreetLegend-Android-APK` artifact.

A successful workflow is the first proof of compilation and APK export. It does not replace Play Mode or physical-device gameplay testing.
