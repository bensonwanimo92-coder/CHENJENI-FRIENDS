# Street Legend — Combat Game Prototype

A mobile-first street combat prototype inspired by 3D martial-arts fighting games. This is an original project, not a copy of Fighting Tiger assets or characters.

## Prototype
- Touch movement pad
- Punch and kick actions with hit range
- Rival AI that approaches and damages player
- Player/rival health bars
- Victory / defeat state and restart
- Responsive canvas visuals

## Next stages
1. Replace canvas mock fighters with rigged 3D models and animation.
2. Add combat combo chains, block, dodge, grab and throws.
3. Build stages, story missions and rival gangs.
4. Add sound effects, music, settings and save progression.
5. Package into Android APK and test on-device.

Current prototype is a browser-based playable proof of concept. It is not yet a finished 3D game or APK.
